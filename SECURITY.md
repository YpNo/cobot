# Security policy

Supported: the latest release on `main`; older tags receive no fixes.

Report a vulnerability through a private security advisory on this repository (Security tab,
"Report a vulnerability"), or to the owner directly when the repository is private. Do not open a
public issue. Expect an acknowledgement within a week and a fix or a decision within thirty days.

Scope: the hook scripts and the `cobot-*` executables, the default rules, and the install
script. Out of scope: the model's own judgement, which the gate bounds but does not replace, as
`README.md` (section Security) explains.
