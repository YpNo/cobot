# Delivery principles — verified facts and versions

Format: `- [verified|reported YYYY-MM-DD · src: <url>] claim`. Version lines are flagged after 30
days, idiom after 90 (`cobot-memory knowledge --stale expert-cicd`).

## Required checks and pipelines

- [verified 2026-11-08 · src: https://github.com/re-actors/alls-green] Aggregator pattern: one `check` job lists every other job in `needs` and is the only required check; it must run `if: always()` or a skipped dependency reports `skipped`, not `failed`.
- [verified 2026-11-08 · src: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/collaborating-on-repositories-with-code-quality-features/troubleshooting-required-status-checks] GitHub: a path-filtered required workflow stays Pending and blocks merging; jobs skipped by conditionals report Success; use `always()` with `needs`.
- [verified 2026-11-08 · src: https://docs.gitlab.com/user/project/merge_requests/auto_merge/] GitLab: "Pipelines must succeed" refuses a merge request with no pipeline, and counts only merge request pipelines when several types run.
- [verified 2026-11-08 · src: https://trunkbaseddevelopment.com/short-lived-feature-branches/] Trunk-based development: commit to trunk at least daily; a feature branch lasts a couple of days at most, one developer (two if pairing), merged then deleted.
- [verified 2026-11-08 · src: https://dora.dev/guides/dora-metrics-four-keys/] DORA metrics: change lead time, deployment frequency, failed deployment recovery time (replaced MTTR), change fail rate, plus deployment rework rate.
- [verified 2026-11-08 · src: https://dora.dev/research/2025/dora-report/] Latest DORA report: "State of AI-assisted Software Development 2025"; the 2024 report is "Accelerate State of DevOps 2024".
