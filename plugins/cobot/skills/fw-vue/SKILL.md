# fw-vue

Thin on purpose: TypeScript, Node, pnpm, Vitest and lint ground is `lang-typescript`; this skill
holds only what Vue changes. CONTEXT.md and the governance file override it. Versions:
`references/versions.md`; re-verify a line the brief flags stale before relying on it.

## Shape

- [verified 2026-11-10 · src: https://vuejs.org/guide/introduction.html] Composition API with single-file components for applications; Options API is built on it, so legacy Options code stays valid. Keep a file in its existing style; do not rewrite it while touching it.
- One component per `.vue` file, `<script setup lang="ts">` first, then `<template>`, then
  `<style scoped>`. Composables in `src/composables/useX.ts`, stores in `src/stores/`.

## Props, emits, models, slots

- [verified 2026-11-10 · src: https://vuejs.org/guide/components/props.html] `defineProps<{ title?: string }>()`; since 3.5 destructured props stay reactive and take native defaults: `const { size = 'md' } = defineProps<…>()`.
- [verified 2026-11-10 · src: https://vuejs.org/guide/components/props.html] Pass a destructured prop to `watch` or a composable as a getter: `watch(() => size, …)`; a bare `watch(size)` does not track.
- [verified 2026-11-10 · src: https://vuejs.org/guide/typescript/composition-api.html] Emits as named tuples: `defineEmits<{ change: [id: number] }>()`.
- [verified 2026-11-10 · src: https://vuejs.org/api/sfc-script-setup.html] `defineModel<string>({ required: true })` is a `Ref<string>`; a `default` used when the parent passes nothing desynchronises parent and child.
- [verified 2026-11-10 · src: https://vuejs.org/api/sfc-script-setup.html] `defineSlots` types slots only; `generic="T extends …"` for generic components; `defineOptions` instead of a second `<script>` block.

## Reactivity

- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/reactivity-fundamentals.html] `ref()` by default. `reactive()` holds no primitives, cannot be replaced wholesale and loses reactivity on destructure; refs inside reactive arrays, Maps and Sets are not unwrapped; templates unwrap top-level refs only.
- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/computed.html] Computed getters are pure (no async, no DOM, no writes) and read-only; copy before `sort()` or `reverse()`.
- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/watchers.html] `watch` tracks its source; `watchEffect` tracks synchronous reads only, nothing after the first `await`. `once: true`, numeric `deep`, `flush: 'post'` for DOM work.
- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/watchers.html] `onWatcherCleanup` must be called synchronously; in async callbacks use the `onCleanup` argument. A watcher created asynchronously is not bound to the component: stop it yourself.
- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/template-refs.html] `useTemplateRef('key')` is `null` until mounted; refs in `v-for` are an unordered array; `<script setup>` components are closed unless `defineExpose` runs before any `await`.
- [verified 2026-11-10 · src: https://vuejs.org/guide/typescript/composition-api.html] provide and inject through a shared `Symbol() as InjectionKey<T>`; `inject` returns `T | undefined`.
- [verified 2026-11-10 · src: https://vuejs.org/guide/essentials/list.html] Primitive `:key` values, never objects; never `v-if` with `v-for` on one element (filter in a computed or wrap in `<template v-for>`).

## State and routing

- [verified 2026-11-10 · src: https://pinia.vuejs.org/core-concepts/] Setup stores return every piece of state (private state breaks SSR and devtools); destructure state and getters with `storeToRefs()`, actions directly; name stores `useXStore`.
- [verified 2026-11-10 · src: https://router.vuejs.org/guide/advanced/typed-routes.html] Typed routes by augmenting `TypesConfig.RouteNamedMap`, or generated by file-based routing.
- [verified 2026-11-10 · src: https://vuejs.org/guide/built-ins/suspense.html] `<Suspense>` is still experimental; a top-level `await` in `<script setup>` makes the component an async dependency.
- [verified 2026-11-10 · src: https://vuejs.org/guide/scaling-up/ssr.html] SSR: invalid nesting, random values and time zones cause hydration mismatches; move them to `onMounted`; a fresh app, router and store per request.

## Tests and commands

- [verified 2026-11-10 · src: https://test-utils.vuejs.org/guide/advanced/stubs-shallow-mount.html] `mount` with targeted `global.stubs`; `shallowMount` stubs everything and skips slots.
- [verified 2026-11-10 · src: https://test-utils.vuejs.org/guide/advanced/async-suspense.html] `await trigger()` and `await setValue()` cover Vue updates; `await flushPromises()` covers mocked HTTP; async setup needs a `<Suspense>` wrapper.
- [verified 2026-11-10 · src: https://pinia.vuejs.org/cookbook/testing.html] `createTestingPinia({ createSpy: vi.fn })` in component tests (actions stubbed); `setActivePinia(createPinia())` in `beforeEach` for store tests.
- [verified 2026-11-10 · src: https://github.com/vuejs/language-tools/blob/master/packages/tsc/README.md] Type check with `vue-tsc --noEmit` (writes nothing); plain `tsc` does not read `.vue` files.
- [verified 2026-11-10 · src: https://eslint.vuejs.org/user-guide/] Flat config `...pluginVue.configs['flat/recommended']`; TypeScript through `@vue/eslint-config-typescript` or `parserOptions.parser`, never the top-level `parser`.
- Commands that write: `eslint --fix`, `vitest -u`, `vitest --coverage`, `vue-tsc -b` or `vue-tsc`
  without `--noEmit` (a repository's `typecheck` script is often `vue-tsc -b`), and the vue-router Vite plugin (`route-map.d.ts`). Name them before running.

## Security

- [verified 2026-11-10 · src: https://vuejs.org/guide/best-practices/security.html] Never use untrusted content as a template (arbitrary code; under SSR a server compromise); never mount Vue on server-rendered nodes holding user content.
- [verified 2026-11-10 · src: https://vuejs.org/guide/best-practices/security.html] Interpolations and bindings are escaped; `v-html`, `innerHTML` and `h(…, { innerHTML })` are not: sanitise, or render user HTML in a sandboxed iframe.
- [verified 2026-11-10 · src: https://vuejs.org/guide/best-practices/security.html] `:href="userUrl"` runs `javascript:` URLs: the backend validates URLs before storing them; user styles only through object syntax; never bind user strings to `on*`.
- [verified 2026-11-10 · src: https://vite.dev/guide/env-and-mode.html] `VITE_*` values are baked into the client bundle; never put a secret there.

## Do not

- Do not convert Options API files to Composition while fixing something else.
- Do not adopt Vapor Mode or Vue 3.6 prereleases unless the spec says so.
- Do not run a command that writes (`--fix`, `-u`, codegen) without naming it in the report.
